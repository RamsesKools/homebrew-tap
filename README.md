# homebrew-tap

Homebrew tap for [wayfinder-maps](https://github.com/RamsesKools/wayfinder-maps), macOS only.

```sh
brew install RamsesKools/tap/wayfinder-maps
brew upgrade wayfinder-maps
```

- `Casks/` is written by the wayfinder-maps `release` workflow, please don't edit it by hand.
- The binary is unsigned, so the cask strips the quarantine flag after install.
- Skills for your agent: `wayfinder-maps install-skill`.
